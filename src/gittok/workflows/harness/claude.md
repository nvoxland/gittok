## In Claude Code

- **The `gittok` server.** Its tools are named `mcp__gittok__<tool>`. Claude Code starts it from `.mcp.json` when the user starts `claude` in the GitTok directory and approves the `gittok` server. If the tools are missing, or after a `server`, `render` or `data_dir` setting changes, ask the user to run `/mcp`, pick gittok, and approve or Reconnect.
- **Start a worker** with the Agent tool: `subagent_type` is the worker's name (for example `gittok-writer`), `model` is the model that the step names, and `prompt` is exactly the identifiers that the step names. Always pass `model` when the step gives one. When it is null, leave `model` out: the worker file says `model: inherit`, so the worker uses the session's model. Start parallel workers as parallel Agent calls in one message. If the worker's type is not available (the session started before it was installed), use `general-purpose` with the same `model` (or none when it is null) and this prompt: `Read .claude/agents/<worker>.md of this directory and follow it.` followed by the identifiers. Never pick opus yourself. Use it only when `agent.models` names it (the step then gives it) or the user asked for it in this request.
- **Run another GitTok skill** with the Skill tool: `/gittok-profile-repo <repo>`, `/gittok-generate`, `/gittok-steer`.
- **Run a shell command** with Bash; a long one that should wake you when it ends with `run_in_background`.
- **Images.** Claude Code has no native image tool: `gittok-illustrator` workers draw agent images as SVG. When you tell the user about image setup and `renderer_setup.illustration.installed` is false, add one line: the images are simple drawings, and on Apple silicon the `images` extra gives real illustrations ("Better images in Claude Code" at https://nvoxland.github.io/gittok/getting-started/).
- **Keep generating** in a session that stays open: `/loop 4h /gittok-generate`. Most ticks end at `nothing_to_do` and cost one tool call.
- The `model` in this skill's frontmatter is fixed when the file is generated (`sonnet` for the standard tier). It does not follow `agent.models`. Change it by hand in the skill only if the user asks for a different driver; `gittok update` then keeps your copy as `.bak`.
