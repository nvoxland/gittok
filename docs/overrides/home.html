GitTok

Doomscrolling your code.

GitTok turns your git repos into a TikTok-style feed. Swipe through short posts about the code you work in every day: the function everything depends on, the commit that got reverted twice, the TODO that has waited six years, the two files that always change together.

Get started  → GitHub

What you get

Posts about your own code

Explainers, code cards, charts and diagrams. Memes, comics, tier lists, group chats and horoscopes. All about the repos you add, never about code in general.

Checked against git

Your coding agent writes the posts. GitTok checks every cited commit, file and line before a post reaches your feed.

Swipe sideways to go deeper

Each post starts with a hook. Swipe sideways to get the explanation, the real code and the real diff.

Quizzes that come back

Spot the bug, guess who wrote it, guess when. A quiz you got wrong comes back a day later, then after three days, then a week.

It learns what you like

What you read, like, 👎 and skip shapes the posts that get made next. Or just say it: "less memes, more of the sync engine."

A cast in the comments

Greybeard, Penny, the Archivist, Paranoid Sec and friends argue about your code under every post.

Made for your phone

Pair your phone once with a short code, add it to your home screen, and scroll on the couch.

Private

Everything runs on your machine. GitTok never writes to your repos and calls no model API of its own.
