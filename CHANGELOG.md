# Changelog

## 1.0.0 (unreleased)

First public release.

- A feed of cards about your own git repos: vertical scroll, horizontal depth panels, stories, replies.
- Cards are written by Claude Code through the GitTok MCP server and checked against git before they are stored.
- Repo profiles: per-repo rules, kept as data, that find the code worth teaching.
- Learning: the feed order adapts to what you read, like, and skip.
- Renderers for code, diagrams, charts, memes, and optional illustrations.
- `gittok install` sets up the MCP server, skills, agents, and a LaunchAgent.
- Supported platform: macOS.
